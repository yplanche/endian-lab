No runtime dependencies, Cloudflare account or database are required. Node.js 22+ builds the website. There is no `npm install` step. Automatic paper summaries, theme classification and changed PhD extraction need your own OpenAI API key and compatible model ID in GitHub settings. Your ChatGPT subscription does not supply API billing. Without these settings the existing website still publishes, but updates needing model analysis cannot complete.

## Local preview

From the extracted project folder:

```sh
npm run build
npm test
npm run preview
```

Open http://localhost:4173; press Ctrl+C to stop. Do not open the HTML with `file://`, because dynamic content loads using HTTP. The build works at a domain root or GitHub repository subpath.

## Automatic updates

GitHub Actions checks daily at **07:17 UTC** and on **Run workflow**. Pushes publish edits without making content-service calls. ORCID supplies the journal-article list; primary abstracts and online dates are checked before publication. Featured descriptions are 30–100 words; Latest manuscript summaries are 50–100 words. Papers without usable evidence or a confident theme assignment retain the previous features and are flagged for review. Up to ten new papers are analysed per run; remaining candidates are retried later. Existing ORCID works were baselined on 17 November 2026 rather than bulk-imported.

The original private hosted website has a separate ChatGPT daily task. It does not update this GitHub repository. Follow the included GitHub Actions setup to enable updates on your domain.

## Publishing and privacy

This package has not been installed in your GitHub account and does not change your DNS. GitHub Pages visitors do not need an OpenAI account. The Flightdesk button opens the separately hosted app; that app's source and access settings are not included here. A public repository exposes source and content history. Never add applicant documents, private correspondence or secrets. Paper-figure reuse requires its own verified licence; inclusion of the lab's media does not grant a blanket licence for third-party material.
